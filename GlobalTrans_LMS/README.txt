GlobalTrans Logistics Management System (Portable Package)
========================================================

Folder Structure:
  main.py
  Datasets/
    Login_Dataset.csv
    Admin_Dataset.csv
    Employee_Dataset.csv
    Customer_Dataset.csv
    Contractor_Dataset.csv
    Shipment_Dataset.csv
    Fleet_Dataset.csv

How to Run From Anywhere:
  1. Extract or copy the entire folder into any directory on your computer.
  2. Open a terminal in that folder (or run `python "<path-to-folder>/main.py"`).
  3. `main.py` automatically finds `Datasets/` next to `main.py` regardless of
     the folder path or current working directory.
